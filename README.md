# Homebrew Tap for Doggy Bag

Homebrew tap for installing [Doggy Bag](https://github.com/bradhannah/BudgetForFun), a desktop budgeting app for tracking monthly costs.

## Installation

```bash
brew install bradhannah/doggy-bag/doggy-bag
```

Or:

```bash
brew tap bradhannah/doggy-bag
brew install doggy-bag
```

## Requirements

- macOS on Apple Silicon (ARM64)

## Updating

```bash
brew upgrade doggy-bag
```

## Uninstalling

```bash
brew uninstall doggy-bag
```

To also remove app data:

```bash
brew uninstall --zap doggy-bag
```

## About

Doggy Bag is a desktop budgeting app focused on fixed monthly costs. It answers one question: **"How much do I have left in my doggy bag at the end of month?"**
